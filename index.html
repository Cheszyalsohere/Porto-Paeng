Tentang Saya.

Saya mahasiswa Manajemen Pemasaran (Marketing Management) yang tertarik pada titik temu antara strategi brand, riset pasar, dan kewirausahaan digital.

Framework seperti Aaker, Keller, dan Ansoff Matrix saya terapkan langsung pada UMKM, mulai dari analisis brand sampai pendaftaran HAKI atas laporan analisisnya. Di luar kelas, saya pernah magang di tim kreatif Vici Hub Asia dan memimpin 60 panitia di BEM Polinema.

Saat ini saya terbuka untuk magang digital marketing / brand, dengan target program Management Trainee / MDP setelah lulus.
